# SHUBH Creative Studio — Interactive Portfolio Showcase

Premium portfolio build with an interactive artwork inspection experience.

## Highlights
- Real SHUBH portfolio artwork from the Phase 6.2 portfolio content.
- Featured first project + editorial two-column gallery.
- Category filtering.
- Hover tilt and image motion.
- Full-screen artwork viewer.
- Zoom from 100% to 400% with mouse wheel, buttons and double-click.
- Drag/pan while zoomed.
- Previous/next navigation and thumbnail strip.
- Keyboard shortcuts: Esc, ←/→, +/−, 0 and F.
- Responsive/mobile-friendly viewer.

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Update portfolio content
Edit:
`src/data/portfolio.json`

Add another item with `n`, `title`, `category`, `description`, and `image` pointing to a file in `public/images/`.
